# Design

## 1. Структуры данных

**`GameState`** хранит текущее состояние игры: статус (`setup`, `playing`, `won`), настройки (`length`, `base`), секретное число, историю попыток и время начала и окончания игры. Это один объект, поэтому данные удобно передавать между функциями. Секрет хранится как строка, чтобы не терять ноль в начале, например `0123`.

**`history`** — массив объектов `GuessEntry`. В каждой записи есть введённая комбинация (`guess`), количество быков (`bulls`) и коров (`cows`). Массив сохраняет порядок попыток. Новая попытка добавляется без изменения старого массива:

```ts
return {
  ...state,
  history: [...state.history, entry],
};
```

**`Set`** используется в `isValidGuess()`, чтобы проверить, что цифры не повторяются. Перед проверкой буквы переводятся в нижний регистр, поэтому `a` и `A` считаются одной цифрой.

**`Map`** используется в `countPossibleSecrets()` для сохранения уже вычисленных результатов. Например, ключ `4:10` соответствует длине 4 и системе счисления 10. При повторном вызове результат берётся из кеша.

**Таблица рекордов** — массив объектов с настройками игры, количеством попыток и временем. Результаты сортируются сначала по попыткам, потом по времени. Остаются 10 лучших записей. `localStorage` сохраняет их после перезагрузки страницы.

## 2. Основные алгоритмы

### `generateSecret(length, base, random)`

Функция создаёт массив допустимых цифр и случайным образом выбирает из него `length` символов. Выбранная цифра удаляется через `splice()`, поэтому повторов нет. Параметр `random` позволяет использовать предсказуемые значения в тестах.

### `evaluateGuess(secret, guess)`

Обе строки переводятся в нижний регистр. С помощью `filter()` считаются **быки** — цифры на правильных позициях. Для **коров** используется `filter()` вместе с `includes()`: цифра есть в секрете, но стоит в другом месте.

Например, `secret = '1234'`, `guess = '1325'` → `{ bulls: 1, cows: 2 }`. Функция рассчитана на комбинации без повторяющихся цифр.

### `isValidGuess(guess, length, base)`

Проверяет длину комбинации, допустимые цифры для выбранной системы счисления и отсутствие повторов через `Set`. Вспомогательная функция `createDigitValidator()` возвращает функцию для проверки одного символа. Она используется и здесь, и при вводе в браузере.

### `countPossibleSecrets(length, base)`

Считает количество комбинаций без повторяющихся цифр. Используется рекурсия: на каждой следующей позиции остаётся на одну цифру меньше.

```ts
const result = base * countPossibleSecrets(length - 1, base - 1);
```

Например, при длине 4 и основании 10 получается `10 × 9 × 8 × 7 = 5040`. Результаты сохраняются в `Map`, чтобы не вычислять их снова.

## 3. Сложность алгоритмов (Big O)

`L` — длина комбинации, `B` — основание системы счисления (сколько разных цифр доступно).

| Функция                  | Время                      | Память   | Почему                                                                                               |
| ------------------------ | -------------------------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `generateSecret()`       | O(B + L × B)               | O(B + L) | Создаём набор цифр и L раз удаляем элемент через `splice()`. Удаление может сдвигать до B элементов. |
| `evaluateGuess()`        | O(L²)                      | O(L)     | Для каждой цифры попытки `includes()` может проверить все L цифр секрета.                            |
| `isValidGuess()`         | O(L × B + L)               | O(L + B) | Проверяем L символов по набору из B цифр и создаём `Set` для поиска повторов.                        |
| `countPossibleSecrets()` | O(L), повторный вызов O(1) | O(L)     | Рекурсия делает L шагов. Если ответ уже в `Map`, он возвращается сразу.                              |

В нашей игре `B` может быть только 2, 8, 10 или 16, поэтому оно ограничено небольшим числом. В `generateSecret()` многократное соединение строк в некоторых реализациях JavaScript также может добавлять затраты до O(L²). Кеш `Map` занимает дополнительную память по мере появления новых аргументов.

## 4. Clean Code

- **Разделение задач.** `generateSecret()` создаёт секрет, `evaluateGuess()` считает быков и коров, `isValidGuess()` проверяет ввод. Каждая функция отвечает за свою задачу.
- **Понятные названия.** Например, `createInitialState()`, `addGuessToHistory()` и `submitGuess()` показывают, что делают функции.
- **Ранний `return`.** В `submitGuess()` обработка сразу заканчивается, если игра не идёт, комбинация неверная или уже вводилась.
- **Неизменяемость данных.** Новая история создаётся через `[...state.history, entry]`, а рекорды сортируются в новом массиве. Старые массивы не изменяются.
- **Отдельная работа с браузером.** Игровые функции не создают HTML-элементы. Интерфейс находится в `src/main.ts`, а сохранение рекордов — в `src/storage/leaderboardStorage.ts`.
